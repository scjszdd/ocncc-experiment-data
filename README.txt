OCNCC EXPERIMENTAL DATA

This data-only collection contains selected experimental results and trial records supporting the OCNCC manuscript. It does not contain all underlying records, research software source code, trained models or checkpoints. The coverage and known gaps are described below. MANIFEST.json identifies the source of each included data file, its row count where applicable, and transformations or removed columns. Source archives referenced in the manifest are not included.

Historical source records use the name PGOCN; OCNCC is the corresponding name used in the manuscript. Original method codes are retained: Full = OCNCC-Full; C1/C1_AStar_PP = A*-PP; B1 = Direct Waypoint; E3/E3_single_team_disc = adapted MR.CAP; wo_ds = No DS; wo_side_slip = No SS; wo_contact_migration = No CM.

01_simulation: paired simulation summaries and selected per-scene records. full_nominal_trials.csv contains 60 nominal Full trials reused in the method comparison, the ablation reference group and the nominal corridor condition. ablation_trials.csv contains 180 runs (three removals x 60 seeds). corridor_geometry_trials.csv contains 240 rows (four layouts x 60 seeds), including the reused nominal Full set. comparison_baseline_formal_results.csv contains selected fields from 180 baseline raw formal-result files. Its success field is the original runtime flag and must not be substituted for an independently re-evaluated strict label; comparison_summary.csv contains the archived strict outcome summary. Original absolute run-path fields are excluded; source archive/member provenance is in MANIFEST.json.

02_figure_data: selected archived per-run metric data and summaries. contact_load_medians_10s.csv contains the eight bins used for the final grouped-contact chart, transcribed from the figure generation report; the older five-second bins are retained separately and are not equivalent to these ten-second medians. Fig06b and Fig09 are historical figure-source identifiers, not necessarily the final figure numbers. Units are encoded in column names or source tables.

03_semantic_probe: 20 predefined instructions, each evaluated in five arrangements with four candidate sources (400 method/trial rows). This isolated benchmark ends at proposal authorization or rejection and does not measure physical transport. File path columns to archived images/results are omitted. Counts are provided in summary_by_method.csv. This collection does not contain the original 172-event complete-task audit logs or a confirmed matching frozen source; these records were not located in the inspected materials, and the audit cannot be reproduced from this collection alone.

04_hardware: ten valid OCNCC-Full right-turn trial time series and their outcome table; five valid Leader-Follower trials in each direction and corresponding summaries; and the adjudicated Fixed-Diff left-turn summary with five associated raw runtime logs from which machine paths and network addresses were removed. Use the adjudicated summary for final outcomes: raw log outcome alone does not incorporate video adjudication. This is not a complete hardware archive. Full left-turn per-trial mapping and Fixed-Diff right-turn source records have not been matched here. A failure to match these records does not mean that they do not exist.

The individual files are selected artifacts, not a complete source archive. No machine access paths or API credentials are intentionally included. These data support the stated selected analyses but should not be taken as evidence that every result in the manuscript can be independently reproduced from this collection alone.
